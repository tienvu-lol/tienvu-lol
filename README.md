## About

I'm a freshman studying Computer Engineering at Virginia Tech, working across the stack from firmware on a satellite payload to evaluating how well large language models build usable, accessible software. I like projects where software has to meet hardware, and where "does it actually work for people?" is part of the question.

## What I'm working on

- 🔬 **LLM evaluation research** (HICE Lab): measuring the accessibility and usability of web interfaces generated by LLMs
- ⚡ **Power electronics research** (CPES): power delivery for data centers
- 🛰️ **CubeSat firmware** (Hume Center): embedded software for the Ut ProSat-X optical communications payload
- 🤖 **Robot locomotion**: simulation and tuning for TOBY, a voice-controlled wheeled robot
- 📝 **Learning in public**: planning a self-directed AI/LLM research project, with a paper as the end goal

## Featured projects

### Echelon: LLM-powered opportunity recommendation
An application that uses large language models to recommend opportunities to users based on their profile and goals. Built at a hackathon (Hacklanta / VTHacks).

### Archipelago: decentralized capability sharing for autonomous systems
A decentralized layer that lets autonomous edge systems, such as drones, share capabilities with one another. Co-developed with Jacob Lee, including the pitch and brand. Built at a hackathon (Hacklanta / VTHacks).

### TOBY: voice-controlled wheeled robot (CalHacks)
A team-built two-wheeled robot with hinged legs that you can talk to.

- Speech is interpreted by Grok, which sends commands to an ESP32 motor controller
- YOLO-based vision runs on a Raspberry Pi 5, with an ArduCam time-of-flight camera for depth perception
- Locomotion simulated in MuJoCo, with PyTorch-based tuning planned
- Entered in the SpaceX track, which required integrating real space data

### Racing line prediction with reinforcement learning
A machine learning model that predicts optimal racing lines, trained with Proximal Policy Optimization (PPO).

### Personal portfolio
A portfolio site designed in Figma and built as a working prototype with sidebar navigation and page switching.
